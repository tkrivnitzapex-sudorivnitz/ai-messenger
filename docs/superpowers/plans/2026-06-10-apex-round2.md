# Apex Round 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the app to Apex, fix the attach-button animation glitch, strip reactions/forward/audio-player extras, and de-Telegram the UI (Clean Light popup menu + simple icons, icon-only bot Menu button, Inter font, tail-less uniform bubbles).

**Architecture:** All behavior removals are gated by new `public static final boolean` flags in `app/aimessenger/AppConfig.java` (the fork's central config), checked at the smallest possible suppression point in upstream code. Visual changes go through the fork's existing Clean Light mechanism: `ThemeColors.defaultColors` for colors, new drawables under `TMessagesProj/src/main/res/drawable/`, and `AndroidUtilities.getTypeface` as the single font resolver.

**Tech Stack:** Telegram-Android/Nekogram fork, Java, Gradle. Build: `JAVA_HOME=$HOME/jdks/jdk-21.0.11+10 ANDROID_HOME=$HOME/Android/Sdk ./gradlew :TMessagesProj_App:assembleDebug` (seconds for Java-only changes). Emulator AVD `testavd`, APK output `TMessagesProj_App/build/outputs/apk/debug/`.

**Spec:** `docs/superpowers/specs/2026-06-10-apex-round2-design.md`

**No unit-test infra exists in this repo for UI code; each task's "test" is a successful `assembleDebug` plus targeted grep assertions, with a full on-emulator visual verification pass in Task 9.** Repo root for all paths below: `/home/jacob/android_dev/telegram_app/ai-messenger`.

```java
package app.aimessenger;

import org.telegram.messenger.R;

/** Maps stock Telegram context-menu icons to the Apex stroke set. */
public final class ApexIcons {

    private ApexIcons() {
    }

    public static int remap(int icon) {
        if (icon == R.drawable.menu_reply) return R.drawable.apex_menu_reply;
        if (icon == R.drawable.msg_copy) return R.drawable.apex_menu_copy;
        if (icon == R.drawable.msg_delete) return R.drawable.apex_menu_delete;
        if (icon == R.drawable.msg_select) return R.drawable.apex_menu_select;
        if (icon == R.drawable.msg_pin) return R.drawable.apex_menu_pin;
        if (icon == R.drawable.msg_edit) return R.drawable.apex_menu_edit;
        if (icon == R.drawable.msg_download || icon == R.drawable.msg_gallery) return R.drawable.apex_menu_save;
        return icon;
    }
}
```
